## ~/projects

**[`monocular-drone-slam`](https://github.com/SebMay99/ORB-SLAM2_robot_localization)** — `C++` `ROS` `OpenCV`  
Two-year undergraduate research on SLAM for autonomous monocular drones. C++ scale estimation algorithm using EKF and PID control, real-time camera stream analysis, 70-page thesis.

**[`house-price-predictor`](https://github.com/SebMay99/price-prediction-regression)** — `Python` `Streamlit` `Plotly`  
Regression on the Ames Housing dataset behind a Streamlit app: feature engineering, model comparison and interactive predictions.

**[`magic-gamma-ml_classification`](https://github.com/SebMay99/magic-gamma-ml_classification)** — `Python` `scikit-learn`  
Gamma vs. hadron event classification on the MAGIC telescope dataset. Five algorithms compared, ~87% accuracy after grid search optimization.

**[`pid-magnetic-levitator`](https://github.com/SebMay99/pid-magnetic-levitator)** — `Arduino` `C++` `PCB`  
Magnetic levitation driven by a discrete PID controller. Hall effect feedback loop, custom PCB driver, dual-microcontroller architecture and an LCD/keypad UI.

**[`finance-analytics-dashboard`](https://github.com/SebMay99/finance-analytics-dashboard)** — `Python` `Streamlit` `Excel`  
Turns Excel P&L models into interactive dashboards for fast cost, revenue and margin analysis across business segments.
